# Code de conduite

BUTTON applique le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/) : un espace accueillant et respectueux pour toutes et tous, quels que soient l'expérience, l'origine, l'identité ou le handicap.

En bref : on reste bienveillant, on accepte la critique constructive, on se concentre sur ce qui est bon pour la communauté. Le harcèlement, les insultes et les attaques personnelles n'ont pas leur place ici.

Pour signaler un comportement, contacter le mainteneur, [@lazbutton](https://github.com/lazbutton). Les signalements sont traités avec discrétion.
