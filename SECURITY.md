# Sécurité / Security

## Signaler une faille

Ne pas ouvrir d'issue publique. Utiliser le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability**. Décrire la faille, son impact, et comment la reproduire.

Une première réponse arrive sous une semaine. Le correctif est publié avant toute divulgation publique, et la personne qui a signalé est créditée si elle le souhaite.

## Versions suivies

Seules la plus haute version publiée, celle du canal `stable`, et la branche `main` reçoivent des correctifs. Un correctif de sécurité sort dans une nouvelle version.

---

**Reporting a vulnerability**: please do not open a public issue. Use GitHub's private reporting (**Security** tab, **Report a vulnerability**). You will get a first answer within a week. Only the highest published version, on the `stable` channel, and `main` receive fixes. A security fix ships in a new version.
