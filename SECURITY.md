# Sécurité / Security

## Signaler une faille

Ne pas ouvrir d'issue publique. Utiliser le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability**. Décrire la faille, son impact, et comment la reproduire.

Une première réponse arrive sous une semaine. Le correctif est publié avant toute divulgation publique, et la personne qui a signalé est créditée si elle le souhaite.

## Versions suivies

Seule la branche `main`, et les images publiées depuis `main`, reçoivent des correctifs.

---

**Reporting a vulnerability**: please do not open a public issue. Use GitHub's private reporting (**Security** tab, **Report a vulnerability**). You will get a first answer within a week. Only `main` and the images built from it receive fixes.
