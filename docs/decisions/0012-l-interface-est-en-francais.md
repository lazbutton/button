# 0012 · L'interface est en français

Acceptée, octobre 2026.

## Contexte

Les premières stations sont des radios associatives francophones. Une interface traduite à moitié est pire qu'une interface dans une seule langue.

## Décision

- L'interface et la documentation sont en français.
- Les fichiers de l'amont, dans `engine/`, restent en anglais.
- Les tickets et les pull requests en anglais sont bienvenus.

## Conséquences

- Tout texte d'interface nouveau est en français, relu comme tel.
- La traduction viendra (FON-09), sans changer la langue de référence.
